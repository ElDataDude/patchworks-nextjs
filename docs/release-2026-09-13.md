# Patchworks AI — 13 September 2026 release

Published to https://patchworks.ai through the existing `eldatadudes-projects/patchworks-nextjs` Vercel project following the user's explicit authorisation.

## Published changes

- Enterprise repositioning across Home, Services, Industries, About and Contact, including shared navigation and booking wording. Existing routes and the agreed historical bodies remain accessible.
- Source Sans 3 replaces Inter for body text, navigation, labels and controls. Instrument Serif headings remain. The homepage supporting paragraph now uses 18–20px text with a 1.65 line height.
- The supplied Lowercase Continuum full-colour and reversed wordmarks replace the previous text logo in every header and footer. Exact supplied PNGs also provide browser, Apple and social icons. Copied assets match the source manifest hashes; favicon.ico wraps the original PNG payloads.
- Resend is deferred at the user's request. Home and Contact present an email enquiry option and booking link, without a disabled form or unavailable-service notice. The form/backend implementation remains in source for the next release, with server configuration absent and sending disabled. No enquiry was sent and no mailbox DNS was changed.

## Verification

- TypeScript, lint, production build, 41 contact endpoint tests and the booking harness passed.
- [141 content checks across 12 routes](../design/enterprise-repositioning/release-content-verification.json) passed against the final local production build.
- Browser checks covered 1440px desktop, 768px tablet, 390px mobile and 320px narrow mobile. No horizontal overflow was observed. The mobile menu opens, focuses Services and closes with Escape while restoring focus. Header/footer artwork loaded at the intended dimensions, and the retained article uses the new font.
- Vercel preview and production builds both completed successfully.
- Live browser readback on `patchworks.ai` and `/contact` confirmed Source Sans 3, both loaded wordmark variants, the revised content, the fixed direct-email link and the correct Cal.com links. No form or unavailable-service notice is rendered in this release.
